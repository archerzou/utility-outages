# Utility Outage API

REST API for the Utility Outage Map, built with [Robyn](https://github.com/sparckles/robyn) and [SQLAlchemy](https://github.com/sqlalchemy/sqlalchemy).

## API Documentation

Interactive API documentation is available via Swagger UI. Start the server and visit:

- **Swagger UI**: [http://localhost:8081/docs](http://localhost:8081/docs)
- **OpenAPI Spec**: [http://localhost:8081/openapi.json](http://localhost:8081/openapi.json)

## Development

```bash
uv run python src/main.py
```
